ระบบแบบประเมินความถนัดทางพหุปัญญา สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3

## About the Project
โครงการนี้เป็นส่วนหนึ่งของปริญญานิพนธ์ (Senior Thesis) พัฒนาขึ้นเพื่อเป็นเครื่องมือประเมินและวิเคราะห์ความถนัดของผู้เรียน (นักเรียน ม.3) แบบออนไลน์ 
ระบบมีการใช้หลักการทางสถิติ Confirmatory Factor Analysis (CFA) ในการวิเคราะห์โครงสร้างแบบประเมิน และใช้ Google Workspace เป็นโครงสร้างพื้นฐานในการจัดการฐานข้อมูล

## Key Features
- **Web-based Assessment:** หน้าเว็บแบบประเมินออนไลน์ที่ใช้งานง่าย รองรับการแสดงผลทุกหน้าจอ
- **Automated Backend:** ประมวลผลคะแนนอัตโนมัติทันทีที่กดส่งข้อมูล
- **Cloud Database:** ข้อมูลทั้งหมดถูกส่งไปจัดเก็บลงใน Google Sheets อย่างเป็นระเบียบแบบ Real-time
- **AI-Assisted Development:** ประยุกต์ใช้ Generative AI เป็นผู้ช่วยในการเขียนโค้ดหลังบ้าน (Backend Logic) และช่วยแก้ปัญหาการเชื่อมต่อระบบ

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend / API:** Google Apps Script
- **Database:** Google Sheets
- **Analysis Method:** Confirmatory Factor Analysis (CFA)

## System Workflow
1. ผู้ใช้ทำแบบประเมินผ่านหน้าเว็บ (Frontend)
2. ระบบส่งข้อมูลผ่าน Google Apps Script
3. คำนวณคะแนนและบันทึกผลลงใน Google Sheets ทันที
